# Optional patches for various KDE components

This folder contains optional patches that are too small and/or insignificant to be maintained through forks. Unlikely to be actively maintained and/or supported, use carefully.

Current patch list:

1. Shortcut indicator fix (kguiaddons) - Reorders the shortcut overlay for desktop icons so that the shortcut indicator appears on the bottom left instead of the bottom right. Dolphin's icons aren't affected by this patch.
